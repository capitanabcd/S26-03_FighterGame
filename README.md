Dragon Ball Z inspired 2D fighting game built in C++ using SFML library. Game implements Object Oriented techniques
to make a scaleable game.

Features animated characters with animations for movement, Idle, attack etc.
Contains a variety of moves, with different animations for each character
Dynamic healthbar has been incorporated that shows player's remaining health.

Movement: 
Player 1 is controlled by using WASD keys.
Player 2 is controlled by using up, right, left, down keys.

Moves:
There are 3 types of moves for every character; A short basic attack, heavy attack and a ranged attack

Player 1: E for Basic attack, F for heavy attack and Q for ranged attack
Player 2: K for basic attack, J for heavy attack and L for ranged attack

SFML 2.6.2 needed as a prerequisite

assets/ folder needs to be in the same directory as executable.
